# Balance

DaVinci Resolve 에서 그룹으로 묶은 컷들의 노출과 화이트밸런스를 기준 컷에 맞춰 주는 샷 밸런싱 도구입니다.
"정노출"을 정하지 않습니다. 노출 의도는 사람이 기준 컷과 버튼으로 정하고, 앱은 그룹 안의 일관성만 맞춥니다.

버전 0.1 (v1 범위). 이름은 가칭입니다.

## 무엇을 하나

- 같은 인물의 스킨끼리 비교해서 컷마다 필요한 노출(스톱)과 화이트밸런스 게인을 구합니다.
- 기준 컷에 없는 인물만 나오는 컷은, 두 인물이 함께 나온 컷을 다리 삼아 이어 붙입니다.
- 얼굴이 없는 컷(인서트)은 이미 맞춰진 컷들의 밝기 분포와 중성색에 맞춥니다. 확신이 낮으면 값을 제안만 하고 적용하지 않습니다.
- 플리커, 출렁임, 스트로브, 컷 안 노출 변화를 구분해서 컷 하나에 대표값 하나를 씁니다. 키프레임은 만들지 않습니다.
- 값은 세 층으로 저장합니다: `최종 = 자동 매칭값 + 그룹 의도 + 컷 의도`. 버튼 한 번은 1/3 스톱(Shift 1/10, Ctrl 1)입니다.
- 값은 타임라인 위치가 아니라 소스(파일명과 소스 프레임 범위) 기준으로 저장합니다. 재편집해도, 같은 소스를 쓰는 다른 타임라인에서도 값이 따라옵니다.
- 입력 색공간이 신호와 맞지 않는 컷을 표시합니다(예: Rec.709 소스에 S-Log3 지정).
- 컷 잠금, 매칭 제외, 되돌리기를 지원합니다.

## 실행

### exe (권장)

`build_exe.bat` 을 실행하면 `dist\Balance.exe` 하나가 만들어집니다. 파이썬이 없는 PC 에서도 실행됩니다.
GitHub 에 올리면 `.github/workflows/build.yml` 이 태그(`v0.1.0` 등)를 푸시할 때마다 같은 exe 를 빌드해 릴리스에 붙입니다.

### 소스로 실행

- Windows: `Balance.bat` 더블클릭. 처음 한 번 `.venv` 를 만들고 필요한 패키지와 얼굴 모델을 받습니다.
- Resolve 없이 둘러보기: `Balance_demo.bat`
- macOS: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python tools/get_models.py && .venv/bin/python -m balance`

Python 은 3.10 에서 3.12 (64비트)를 권장합니다. Resolve 의 스크립팅 모듈이 이 범위에서 가장 안정적입니다.
창은 설치돼 있는 Edge 또는 Chrome 을 앱 모드로 띄웁니다. 창을 닫으면 앱도 끝납니다.

## Resolve 쪽 준비

1. DaVinci Resolve Studio 를 실행합니다. 환경설정 > 시스템 > 일반에서 "외부 스크립트 사용"을 "로컬"로 바꿉니다.
2. 컬러 페이지에서 입력 변환(CST 노드 또는 컬러 매니지먼트) 바로 다음에 노드를 하나 만들고 라벨을 `EXPOSURE` 로 바꿉니다.
3. 그 노드를 우클릭해 Gamma 를 Linear 로 바꿉니다.
4. 이 노드 구성을 모든 컷에 복사합니다.

Resolve 의 스크립팅 API 는 노드를 만들거나 Gamma 를 바꾸는 기능이 없어서 2~4번은 직접 해야 합니다.
앱은 라벨로 노드를 찾아 `SetCDL` 로 Slope 만 씁니다. 이 노드는 Balance 전용으로 두세요. 값을 쓸 때마다 그 노드의 프라이머리를 덮어씁니다.

Gamma 를 Linear 로 두는 이유: 노출은 선형 공간의 곱셈이기 때문입니다. DI 타임라인의 Offset 도 비슷하게 동작하지만 `(L + 0.0075)` 에 대한 게인이라 섀도에서 어긋납니다(미드그레이에서 1스톱이 0.0733 이 아니라 0.0712). 설정에서 Offset 방식으로 바꿀 수 있습니다.

## 쓰는 순서

1. 앱을 띄우면 현재 타임라인의 컷이 썸네일로 나옵니다.
2. 컷을 골라 `G` 로 그룹을 만들거나, 왼쪽 그룹으로 끌어다 놓습니다. Resolve 의 그룹을 가져올 수도 있습니다(설정).
3. 그룹에서 기준이 될 컷을 고르고 `R` 을 누릅니다. 기준 컷이 없으면 그룹 중앙값에 맞춥니다.
4. "자동 매칭"을 누릅니다. 분석이 끝나면 값이 EXPOSURE 노드에 들어갑니다.
5. 컷 또는 그룹 전체를 고르고 `↑` `↓` 로 의도를 더합니다. 노란 고리가 붙은 컷은 확신이 낮아 적용하지 않은 제안값입니다. 오른쪽 패널에서 켤 수 있습니다.

`\` 를 누르고 있으면 촬영본 그대로를 보여 줍니다. `?` 로 단축키 전체를 볼 수 있습니다.

## 입력 색공간

분석은 원본 파일을 직접 읽어 DaVinci Wide Gamut 선형으로 바꾼 뒤에 합니다. 그래서 컷마다 입력 색공간을 알아야 합니다.

- 컬러 매니지먼트(RCM) 프로젝트: Resolve 에 지정된 Input Color Space 를 그대로 씁니다.
- CST 노드 방식: API 로 CST 노드 설정을 읽을 수 없습니다. 파일 메타데이터에 단서가 있으면 그것을, 없으면 설정의 "로그 소스 기본 입력"을 씁니다. 다르면 컷을 골라 오른쪽 패널에서 바꿔 주세요(여러 컷을 한 번에 바꿀 수 있습니다).

신호만으로 확실히 가릴 수 있는 것은 로그와 Rec.709 의 구분까지입니다. S-Log3, LogC3, LogC4 는 블랙 코드값이 같아서 신호로는 구분되지 않습니다.

## 읽을 수 있는 소스

ProRes, DNxHR, XAVC(H.264/HEVC) 등 내장 FFmpeg 이 여는 포맷. FFmpeg 은 패키지 안에 들어 있어 PC 에 따로 설치할 필요가 없습니다.
R3D, BRAW, ARRIRAW, X-OCN, Cinema RAW Light 는 직접 읽지 못합니다. Resolve 에서 프록시를 연결해 두면 프록시로 분석합니다. 이미지 시퀀스는 아직 지원하지 않습니다.

## 검증한 것과 아직 못 한 것

자동 테스트 86개 (`pip install -r requirements-dev.txt` 뒤 `python -m pytest`):

- 전달함수 14종과 색역 13종을 colour-science 구현과 수치 대조
- 디코더: 기준 구현이 만든 Y'CbCr 을 ProRes, H.264, HEVC 로 인코딩한 뒤 읽어 코드값 대조. 프레임 단위 seek, 데이터 레벨, 601/709/2020 매트릭스
- 정답을 아는 합성 촬영본 28컷으로 분석과 매칭 전체: 스킨 매칭 컷의 오차 0.05 스톱 이내(출렁임 컷 0.12)
- 실제 얼굴 사진으로 검출, 스킨 측정, 인물 매칭: 노출·WB·카메라 인코딩·프레이밍이 달라도 0.08 스톱 이내
- 가짜 Resolve(같은 API 형태)에 대고 스캔부터 `SetCDL` 까지, 세 층 값, 잠금, 제외, 되돌리기, 재편집 뒤 값 승계
- HTTP 서버와 보호 장치, UI 시나리오 30단계(헤드리스 브라우저)

실제 Resolve 가 있어야 확인할 수 있어서 아직 못 한 것. 첫 실행 때 먼저 봐 주세요.

1. 연결 자체: 이 PC 의 Python 버전으로 `fusionscript` 가 올라오는지.
2. Gamma 가 Linear 인 노드에 `SetCDL` 의 Slope 가 선형 게인으로 들어가는지. 컷 하나에 컷 의도를 +1 스톱 주고, Resolve 에서 그 노드의 Gain 이 2.00 으로 찍히고 화면이 정확히 1스톱 밝아지는지 보면 됩니다.
3. 앱이 직접 디코딩한 값과 Resolve 내부 값의 차이. 같은 컷에서 레퍼런스와 맞춘 결과를 스코프로 비교해 주세요.
4. 실제 촬영본에서의 임계값들(스킨 샘플링, 플리커 분류, 신뢰도). 합성 영상과 사진 한 장으로만 맞춘 값이라 실제 MV 몇 편으로 조정이 필요합니다.

## 구조

```
balance/
  color/      로그 커브, 색역 행렬, 입력 색공간 레지스트리, 미리보기 변환
  media/      PyAV 디코더, 합성 촬영본(데모와 테스트)
  analysis/   프레임 측정, 플리커 분류, 얼굴과 스킨, 입력 색공간 추정, 그룹 매칭
  resolve/    Resolve API 연결, 가짜 Resolve
  core.py     엔진: 상태, 세 층 값, 작업, Resolve 쓰기
  store.py    프로젝트별 사이드카 저장소
  server.py   로컬 HTTP 서버 (127.0.0.1 전용)
  web/        UI
tools/        모델 내려받기, 미리보기 데이터 만들기
packaging/    exe 빌드 설정
tests/
```

저장 위치: 설정과 값은 `%APPDATA%\Balance`, 썸네일 캐시는 `%LOCALAPPDATA%\Balance\cache`.
창 없이 뜨는 실행(exe, `Balance.bat`)의 로그는 `%APPDATA%\Balance\balance.log` 에 남습니다. 시작 자체가 실패하면 오류 창이 뜹니다.

## 라이선스 관련

- 얼굴 검출 YuNet (MIT), 인물 인식 SFace (Apache-2.0). OpenCV Zoo 배포본이고 상업적 이용이 가능한 라이선스입니다.
- 글꼴 IBM Plex Sans KR, Barlow Semi Condensed (SIL OFL 1.1).
- 디코딩에 쓰는 PyAV 패키지에는 FFmpeg 이 들어 있고, exe 에도 함께 묶입니다. exe 를 외부에 배포하거나 판매할 계획이면 그 FFmpeg 빌드의 라이선스 조건을 먼저 확인하세요.
